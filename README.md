# RoadToVirtuosity.com

Repository for Road to Virtuosity cloud workflow tooling.

## Status

Initial repository scaffold. No production website code or deployment automation is included.

## Data safety

Keep passwords, API keys, session cookies, personal data, source PDFs, and generated publishing output out of this repository. Use appropriate private storage and approved credential tools instead.

## Cloud setup

Select this repository when creating a Codex Cloud environment. Verify the environment's available tools and service access before using it for production work. Repository initialization alone does not configure external service access or start publishing.
